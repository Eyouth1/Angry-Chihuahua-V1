## Code Guidelines

**JUCE Best Practices:**
- Use `juce::` namespace for JUCE classes
- Audio processing happens in `processBlock()`
- GUI updates via `componentMovedOrResized()`, `resized()`, etc.
- Use `juce::Slider`, `juce::Button`, `juce::Label` for UI components

**C++ Standard:**
- Modern C++17 syntax is OK
- Prefer JUCE containers (`juce::Array`, `juce::String`) over STL
- No C++20 features (VS 2022 with /std:c++17)

**Audio Processing:**
- `processBlock()` must be fast (called in real-time audio thread)
- Avoid allocations, blocking calls, or heavy computation
- Use DSP classes from `juce_dsp` module
